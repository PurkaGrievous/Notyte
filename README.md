# Notyte

**Notyte** is a personal desktop application for managing my video game collection.

The goal of this project is to create one place where I can organize my games, track my progress, and eventually manage game configuration backups and profiles.

## Features

### Planned
- [ ] Add and remove games
- [ ] Organize games by status (Backlog, Playing, Completed)
- [ ] Search and filter the game library
- [ ] Store game information locally using SQLite
- [ ] Add personal notes to games
- [ ] Create and restore game configuration backups
- [ ] Manage different configuration profiles

## Technologies

- Python
- PySide6
- SQLite
- Git & GitHub

## Running the project

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```
